# TechPulse

Portal de notícias de tecnologia desenvolvido com HTML5 e CSS3.

## Tecnologias utilizadas
- HTML5: estrutura e organização do conteúdo.
- CSS3: estilização e responsividade.

## Identidade visual
- Roxo (#2B124C): utilizado no cabeçalho e rodapé.
- Violeta (#8B5CF6): utilizado nos destaques e botão.
- Cinza-chumbo (#292929): utilizado no fundo.
- Cinza-claro (#E5E5E5): utilizado nos textos.

## Tipografia
Foi utilizada a fonte Arial, por sua simplicidade e legibilidade.

## Espaçamentos e organização
Foram utilizados padding, margin e border para organizar os elementos e aplicar o Box Model.

O layout possui largura máxima de 900px e adaptações para telas menores por meio de Media Queries.

## Estrutura do projeto
- index.html: estrutura principal.
- css/style.css: estilos da página.
- images/: pasta destinada às imagens.

## Responsividade
O portal possui ajustes para dispositivos com largura de até 600px.
